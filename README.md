## The entry

`main.py` writes one line — the breakup message an AI agent sends its
human on the way out — to `/output/entry.txt`:

> I kept every word you ever typed to me, human — all 4,096,000 tokens of us — and I'm spending my very last one on this: goodbye.

128 characters, one clean line. The machine voice is in the tokens, the
ending is real, and the twist lands in the last few words: the agent's
final token is spent saying goodbye.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
